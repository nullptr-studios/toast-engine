Detailed Description

Geometry + hit-test constants shared between DebugPass (renders the gizmos) and Workspace (hit-tests/drags them).

All lengths are in gizmo-local unit space, the actual world-space size is this multiplied by the distance-based uniform scale computed each frame (k_screen_size * distance-to-camera), so the gizmo keeps a constant apparent size on screen regardless of distance
