Detailed Description

Global registry mapping fully-qualified type names to NodeInfo pointers.

The singleton is populated by registerEngineTypes(), which is generated by refgen and called at engine startup. After startup the registry is read-only from user code.

Note
Do not call registerNode() directly; it is reserved for generated registration functions
