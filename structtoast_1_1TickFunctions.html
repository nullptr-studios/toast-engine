Detailed Description

Set of lifecycle function pointers for one Node type.

Generated by the reflection tool; one pointer per lifecycle phase. A null pointer means the type does not implement that phase. The list bitfield mirrors the non-null pointers for O(1) phase-presence checks without dereferencing.

Note
Do not call these directly; go through Node::callTick()
