Detailed Description

A set of clips plus the skins they pose.

The format holds many clips, but the importer writes one per file so each is its own asset in the browser. Every file carries the skins too, so any one can pose the skeleton alone - and a glTF with skins but no animations still produces a clip-less file for MeshNode::skin_animation to point at
