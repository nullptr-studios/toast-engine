Detailed Description

Everything the editor needs to render a setting without knowing what it is.

The point of carrying this on the setting rather than in the editor: a system declares its settings next to the code that reads them, and the settings window picks them up with no C# change. category is the grouping header, defaulting to the key minus its last segment
