◆ setRoot()

auto toast::World::setRoot ( Node & node) -> Box< Node >
static

Promotes a cached or global node to be the active world root.

Calls end() on the old root and begin() on the new one so there is never a frame with two simultaneous active roots.

Parameters
nodeMust be in the cached or global state with NodeType::root
Returns
The previous world root, now cached, or an empty box if the world was empty
Warning
Passing an already-rooted node is a no-op; a warning is logged
