Detailed Description

Keyframe animation asset (.tanim), imported from glTF.

Author
dario

One clip plus the skins it poses, one file per animation the glTF defines. Sampled by toast::AnimationPlayer, GPU-skinned by renderer::SkinningPass

Bump _detail::animation_format_version on any layout change

Enumerator
cubic_spline 

Cubic Hermite. Each keyframe stores three values (in-tangent, value, out-tangent) rather than one, so a cubic track's value array is 3x as long as its time array
