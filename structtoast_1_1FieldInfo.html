Detailed Description

Runtime descriptor for one reflected field.

Holds type metadata, JSON attributes parsed from the header annotation (e.g. Group, Name), and a type-erased getter/setter pair that works without knowing the concrete Node subtype.

Note
The getter returns std::any; the setter silently does nothing on a type mismatch
