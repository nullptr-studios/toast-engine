Detailed Description

Reference-count control block embedded inside the Node allocation.

Lives immediately before the Node in a single contiguous heap block so that Box<Node> handles need no separate allocation. ControlBox is an implementation detail; user code should interact exclusively through Box<Node>.

Note
Copy and move are deleted: the ControlBox must never move in memory because all Box handles hold raw pointers to it
