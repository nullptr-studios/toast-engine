Detailed Description

Central FMOD system manager.

Maintains two instance models: 2D events share one FMOD instance per GUID (since you rarely play the same 2D event multiple times overlapping), while 3D events get a unique uint64 handle returned per play() call so you can track them independently. Listeners and volumes register themselves to coordinate spatial audio state each frame
