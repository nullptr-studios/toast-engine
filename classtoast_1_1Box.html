Detailed Description

template<typename T>
class toast::Box< T >

Intrusive reference-counted handle to a Node.

The ControlBox lives inside the Node allocation itself, so all Box<Node> handles that refer to the same node share one reference count without any extra heap allocation. This design also makes the ref-count safe across DLL boundaries, where std::shared_ptr's control block would differ between modules.

A Box is null (empty) when default-constructed or after the node has been freed. Always call exists() before dereferencing.
