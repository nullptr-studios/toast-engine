Detailed Description

Base interface for audio-reactive volumes.

Each frame, listener weights accumulate via evaluateTarget. After all listeners are processed, finalizeAccumulators is called once, then onVolumeTick fires so subclasses can push state to FMOD based on the frame's accumulated data
