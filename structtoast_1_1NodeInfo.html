Detailed Description

Complete reflection record for a registered Node type.

Populated by the generated Reflect<T> specialization at program startup. base_type chains through C++ inheritance so that field lookups and isA() checks traverse the full type hierarchy without RTTI.

Note
NodeInfo instances are static globals; comparing two NodeInfo pointers for equality is a valid way to test for identical types
