enum class toast::settings::Layer : uint8_t
strong

Where a value comes from, lowest priority first.

code is the default passed to declare() and is never written to disk. project is authored in the editor and ships with the game. user is what a player's own tweaks land in, so a patch that changes a project default still reaches players who never touched that setting

A resolved value is the highest layer that has an override, so writing one layer never destroys another
